# 🛰️ نظام الاستشعار الراداري والمحاكاة الهيدرولوجية للصمود أمام الفيضانات
## مسابقة AI4SDGs 2026 | مسار: "رسم خرائط المياه لتعزيز الصمود أمام الفيضانات"
### تنظيم: عدسة عُمان (Oman Lens) بالتعاون مع ستارفيجن (Star.Vision Aerospace)

---

## 📌 نبذة عن المشروع (Executive Overview)
يُعد هذا النظام نموذجاً أولياً عاملاً ومتكاملاً (End-to-End Operational MVP) يدمج بين **بيانات الأقمار الصناعية الرادارية (Sentinel-1 SAR)** و**محاكاة هيدرولوجية فيزيائية ثلاثية الأبعاد مبنية على نماذج الارتفاع الرقمية (DEM)** بهدف:
1. رصد الغمر المائي السطحي الآني بدقة عالية حتى في وجود السحب الكثيفة والعواصف المدارية.
2. التنبؤ بالانتشار الزمني لفيضانات الأودية والسيول الجارفة (Flash Floods) عبر خطوات زمنية متتالية ($T+1h, T+3h, T+6h, T+12h, T+24h$).
3. تقييم المخاطر الميدانية تلقائياً: تحديد الطرق المقطوعة، المباني والأحياء المحاصرة، واقتراح مسارات إخلاء آمنة عبر المرتفعات لدعم غرف عمليات الدفاع المدني وإدارة الأزمات في سلطنة عُمان.

## 🚀 دليل التثبيت والتشغيل السريع (Quickstart Guide)

### 1. المتطلبات الأساسية
- بيئة بايثون الإصدار 3.10 أو 3.11 أو أحدث.

### 2. تثبيت الحزم البرمجية
افتح موجه الأوامر (Terminal / PowerShell) في مجلد المشروع ونفذ:
```bash
pip install -r requirements.txt
```

### 3. تشغيل لوحة التحكم التفاعلية (Streamlit App)
```bash
streamlit run app.py
```
سيتم فتح واجهة غرفة العمليات تلقائياً على المتصفح عبر الرابط المحلي:
`http://localhost:8501`

## 🧪 سيناريو محاكاة تجريبي (Simulation Walkthrough)

1. **اختيار المنطقة الجغرافية وحوض الوادي (Location Switcher)**:
   - من القائمة الجانبية (Sidebar)، اختر الحوض المائي المستهدف:
     * **حوض وادي عدي - محافظة مسقط**: حوض جبلي حضري كثيف يربط طريق العامرات بالسلطان قابوس.
     * **حوض وادي شاب وقلهات - محافظة جنوب الشرقية**: خوانق جبلية صخرية شديدة الانحدار تعبر طريق قريات - صور الساحلي.
     * **حوض وادي عاهن وصحم - محافظة شمال الباطنة**: مروحة فيضية وسهول زراعية ممتدة نحو ساحل بحر عُمان.
     * **حوض وادي دربات وطاقة - محافظة ظفار**: حوض كربوناتي جيري يتأثر بأعاصير بحر العرب المدارية.

2. **اختيار سيناريو العاصفة المدارية**:
   - حدد أحد السيناريوهات التاريخية المسبقة (مثل: **إعصار شاهين 150 ملم**، **إعصار جونو 200 ملم**، أو **إعصار مكونو/تيج 180 ملم**) أو اضبط معدل الأمطار يدوياً.
   - يتكيف معامل نفاذية التربة **SCS Curve Number** تلقائياً مع طبيعة صخور وتربة المنطقة المختارة.

3. **التنقل عبر الخطوات الزمنية ومحاكاة الحركة (Simulation Timeline & Motion Controls)**:
   - استخدم أزرار التحكم بالحركة السريعة (`▶️ تشغيل`، `⏸️ إيقاف`، `🔄 إعادة`) لتشغيل عرض حركي متسلسل يتنقل تلقائياً بين الآفاق الزمنية ($T+1h \rightarrow T+3h \rightarrow T+6h \rightarrow T+12h \rightarrow T+24h$).
   - لاحظ كيف يرتفع منسوب المياه تدريجياً وتتوسع رقعة الغمر من مجرى الوادي الضيق إلى السهول الحضرية في الخريطة والمؤشرات في آنٍ واحد.
   - ستظهر خطوط **مسارات السيول الجارفة (Flash Flood Paths)** باللون البرتقالي الساطع مبرزة قنوات الاندفاع القصوى.

4. **الرسم البياني الحركي التفاعلي (Plotly Graph Motion)**:
   - يتضمن النظام رسماً بيانياً حركياً متقدماً يعرض ديناميكية انتشار الفيضان لحظة بلحظة.
   - يتكامل فيه منحنى هيدروغراف الغمر المائي (Spline Area Curve باللون السياني المتوهج) مع أعمدة تراكم الأمطار الهيدرولوجية.
   - يتيح الرسم زري `Play` و `Pause` مدمجين مع شريط تمرير زمني تفاعلي وانتقالات انسيابية ناعمة (Smooth Cubic Transitions) ومؤشر وميض حي (`Active Pulse Marker`) يُحدد موضع المرحلة الزمنية الحالية بدقة.

5. **رصد الأقمار الصناعية (Sentinel-1 SAR)**:
   - فعّل طبقة "رصد الأقمار الصناعية" لمقارنة المياه الراكدة المرصودة فعلياً بالانعكاس الراداري مع توقعات المحاكاة الرياضية.

6. **لوحة المؤشرات الفورية (Real-time KPIs)**:
   - **مساحة الغمر المتوقعة**: تتغير ديناميكياً بناءً على الحوض المختار وكمية الأمطار.
   - **نسبة انقطاع الطرق**: ترتفع مؤشرات الخطر ليظهر تنبيه فوري بانقطاع الشرايين الحيوية نتيجة تجاوز عمق المياه 0.6 متر.
   - **السكان المعرضون للخطر**: حصر تلقائي للمباني والعيادات الواقعة في نطاق الخطر.

7. **مسارات الإخلاء الآمنة (Evacuation Corridors)**:
   - يُنشئ النظام خطوط إخلاء باللون الأخضر المتقطع تتجنب بطون الأودية وتوجه الفرق والمدنيين إلى مراكز الإيواء الآمنة في المرتفعات المحددة لكل منطقة.

8. **الأحواض الفرعية ومواقع سدود التهدئة المقترحة (Structural Mitigation)**:
   - فعّل طبقة "الأحواض المائية الفرعية (Sub-basins)" لمعاينة تقسيم الحوض الرئيسي إلى أحواض تصريف مستقلة.
   - فعّل طبقة "مواقع سدود التهدئة المقترحة (Proposed Dams)" لرؤية مواقع السدود المختارة خوارزمياً عند خوانق الأودية الجبلية الضيقة لحجز كميات السيل وتهدئة اندفاعه، مع تقدير سعتها التخزينية وفق توصيات دراسات إدارة مخاطر الفيضانات.

9. **تصدير التقرير الرقمي**:
   - انقر على زر "تصدير تقرير العمليات الرقمي (JSON)" لتحميل تقرير قياسي يمكن إرساله مباشرة لفرق المستجيب الأول وغرف الدفاع المدني.

## 🎯 القيمة المضافة ومواءمة أهداف التنمية المستدامة (SDGs)
- **SDG 11 (مدن ومجتمعات محلية مستدامة)**: حماية الأرواح والبنية الأساسية من الكوارث الطبيعية عبر تخطيط حضري مرن وتحديد مواقع سدود الحماية ومسارات إخلاء ذكية.
- **SDG 13 (العمل المناخي)**: بناء قدرات التكيف المؤسسي والاستجابة الاستباقية للظواهر الجوية المتطرفة في الشرق الأوسط وسلطنة عُمان.
- **رؤية عُمان 2040**: تعزيز جاهزية منظومة إدارة الطوارئ والأزمات الوطنية عبر تقنيات الفضاء والذكاء الاصطناعي.
