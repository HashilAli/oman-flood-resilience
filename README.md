# 🛰️ منظومة راصد عُمان: المحاكاة الهيدروليكية ثلاثية الأبعاد للصمود أمام الفيضانات

---

## 📌 نبذة عامة (Executive Overview)

تم تطوير هذا المشروع إلى **منصة متكاملة لمحاكاة فيضانات الأودية والسيول الجارفة ثلاثية الأبعاد على التضاريس الحغرافية الحقيقية لسلطنة عُمان**. 

تتميز المنصة بالفصل الكامل بين:
1. **الحسابات الفيزيائية الهيدروديناميكية**: محرك عددي ثنائي الأبعاد (2D Local Inertial Shallow Water Solver) محافظ تماماً على الكتلة (نسبة خطأ 0.000%) ومقيد بشرط الاستقرار العددي CFL، ونموذج فواقد الرشح التراكمي SCS-CN.
2. **البيانات المكانية الحقيقية**: استيراد نوافذ تضاريس حقيقية من **Copernicus DEM GLO-30** بدقة 30 متراً عبر AWS Open Data بصيغة COG، وبيانات الطرق والمباني وقنوات الأودية الطبيعية من **OpenStreetMap**.
3. **العرض البصري ثلاثي الأبعاد**: واجهة تفاعلية متطورة مبنية بـ **CesiumJS** مع شريط زمني متزامن يتنقل بين طبقات الغمر المحسوبة مسبقاً دون إعادة حساب النموذج في المتصفح أو اختلاق حركة مياه عشوائية.

## 🚀 دليل التثبيت والتشغيل السريع (Quickstart Guide)

### 1. المتطلبات الأساسية
- بيئة Python 3.10 أو 3.11 أو أحدث على نظام Windows / Linux.

### 2. تثبيت الحزم البرمجية
```bash
pip install -r requirements.txt
```

### 3. تشغيل المنصة ثلاثية الأبعاد (3D Cesium Platform - النظام الأساسي)
شغّل خادم FastAPI:
```bash
python -m uvicorn src.api.server:app --host 0.0.0.0 --port 8000
```
افتح المتصفح على:
👉 **`http://localhost:8000`**

وستحصل على:
- خريطة تفاعلية ثلاثية الأبعاد لتضاريس سلطنة عُمان عبر CesiumJS.
- قائمة بأحواض الأودية المجهزة (وادي عدي، وادي شاب، وادي عاهن، وادي دربات) مع إمكانية إدخال إحداثيات مخصصة.
- تحكم بشدة الأمطار ومدتها ومعامل نفاذية التربة (SCS-CN) وخشونة مانينغ.
- تشغيل المحاكاة في الخلفية ومتابعة شريط التقدم اللحظي.
- شريط زمني تفاعلي للتنقل بين مراحل الفيضان وتشغيل العرض الحركي المتزامن.
- استعلام فوري بالضغط على أي نقطة في الخريطة لإظهار الارتفاع الحقيقي، وأقصى عمق مياه، والسرعة، وزمن الوصول، ورسم منحنى الهيدروغراف.
- تقييم انقطاع الطرق والمباني المتأثرة بناءً على شبكات OpenStreetMap الحقيقية.
- مقارنة السيناريوهات وتصدير النتائج بصيغة GeoTIFF و JSON.

### 4. تشغيل واجهة Streamlit السابقة (Legacy MVP)
للتوافق مع النموذج الأولي السابق:
```bash
streamlit run app.py
```
الرابط المحلي: `http://localhost:8501`

## 🧪 تشغيل حزمة الاختبارات الآلية (Automated Verification)

للتحقق من سلامة كافة الوحدات الرياضية والجغرافية والواجهات البرمجية:
```bash
pytest -v
```

**النتائج المحققة (12 اختباراً ناجحاً):**
- اختبار دقة إسقاط الإحداثيات لمنطقة سلطنة عُمان (UTM Zone 40N).
- اختبار جلب والتحقق من بلاطات Copernicus GLO-30.
- **اختبار حفظ الكتلة الفيزيائي التام (Mass Conservation)** بنسبة خطأ $0.000\%$.
- اختبار بحيرة في حالة سكون (Lake at rest) وعدم حركة المياه في الأسطح المستوية.
- اختبار جريان المياه المتوافق مع الجاذبية وانحدار التضاريس نحو المصارف.
- اختبار نموذج الفواقد SCS-CN وعدم وجود قيم سالبة.
- اختبار مهايئ HEC-RAS 2D واكتشاف جاهزية البيئة.
- اختبار تكامل الـ API: استيراد التضاريس، وإطلاق المحاكاة الخلفية، واستعلام النقاط، وتوليد صور الطبقات.
